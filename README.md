# Gym Membership Behavior Analysis

## Project Overview
This project analyzes gym membership data to understand seasonal demand patterns, revenue trends, and member engagement across different periods of the year.

The analysis explores how gym memberships fluctuate during key periods such as New Year fitness resolutions, mid-year fitness goals, and end-of-year spikes. The goal is to provide insights that help fitness businesses better understand customer behavior and optimize operational planning.

## Objectives
- Analyze seasonal membership patterns
- Identify peak demand periods
- Evaluate revenue performance across months
- Understand member behavior and retention trends

## Tools Used
- SQL Server
- Power BI
- Excel
- Data Modeling (Star Schema)

## Data Model
The project uses a star schema including:

- `fact_membership`
- `dim_member`
- `dim_date`
- `dim_plan`

This structure allows efficient analysis of membership activity and revenue.

## Key Insights
- Membership registrations peak during the **New Year period** due to fitness resolutions.
- A second spike occurs around **mid-year months** as individuals pursue fitness goals.
- Membership activity declines during certain months before increasing again towards year-end.

## Dashboard Features
The Power BI dashboard includes:

- Total Revenue
- Total Members
- Average Revenue per Member
- Monthly Revenue Trends
- Membership Activity by Seasonal Period

## Business Recommendations
- Increase marketing campaigns during peak signup seasons
- Offer promotional packages during slower months
- Improve retention strategies for returning members

## Project Outcome
This project demonstrates how data analytics can help fitness businesses understand customer behavior and make data-driven operational decisions.
